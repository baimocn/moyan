# 墨衍 · 部署与回滚清单（OBS-02）

*2026-09-05 M4 Phase 9 · 沉淀自本里程碑多次真实部署*

## 标准部署流程

1. **前置**：本地全量 pytest（`--basetemp=out/_pytest_tmp`）全绿；`git diff` 确认改动范围
2. **上传**：SFTP 逐文件（out/_upload_*.py 模板）；目标 `/opt/moyan/`；新目录先 `mkdir -p`
3. **校验**：md5 抽检（注意本地 md5 清单要**上传前现算**，吃过"清单过期"的亏）
4. **DB 变更**：`cd /opt/moyan && /opt/moyan/venv/bin/alembic upgrade head`
   （新迁移必须幂等；生产执行前先跑 SELECT DISTINCT 核实 CHECK 取值域）
5. **重启**：`systemctl restart moyan` → **sleep ≥15s**（冷启动 >4s，实测 000 假象）→ `is-active`
6. **验证**：`/api/health` 200 → 实弹冒烟（归属 404/200、限流 429 等按改动选择）
7. **收口**：commit + push（远端=本地=生产 不变量）

## 回滚

- 单文件：`git show <基线>:<file> > file` → SFTP 重传 → restart → health
- DB 迁移：`alembic downgrade -1`（0002/0003 均有 downgrade）；或按迁移内 SQL 手工逆操作
- 探针误报：`systemctl status moyan-smoke` → 查 `journalctl -u moyan-smoke`

## 已知坑（部署相关）

| 坑 | 对策 |
|---|---|
| uvicorn 冷启动 >4s，health 提前查会得 000 假象 | restart 后 sleep 15 |
| 生产 .env 是 CRLF | `grep + cut + tr -d '\r'`；shell 里拼 URL 做 sed 替换极易翻车——用 Python 脚本做字符串手术 |
| createdb 测试库默认属主 postgres | 必须 `createdb -O moyan`（PG15+ public schema 无公共 CREATE） |
| 远端目录不存在 SFTP ENOENT | 先 `mkdir -p` |
| Mimosa push 门误报 | 测试假密码/参考项目触发；已被用户关闭，如复发走白名单 |
| 前端 dist 部署 | `frontend-web/dist/` → `/var/www/moyan-web/`（index.html + assets 全量） |

## 六、筛选与落地说明

- **不变的部分**（无论选谁）：9 条硬规则、脚手架阶梯、防泄漏、苏格拉底式——人物只是"性格层皮肤"，
  换皮不动引擎。落地时 persona.py 换 PERSONA_SECTION + 开场白模板 + 称呼即可，一次改动一个文件。
- **角色卡五件套**（源自 SillyTavern V2 规范）：人设 description / 性格 personality /
  场景 scenario / 开场白 first_mes / 对话示例 example_dialogue——每个候选实装时补全五件套。
- **通用技术模式**（来自扫描）：中括号动作描写框架、防出戏指令（"任何情况下保持角色设定"）、
  多人格切换配置（Open-LLM-VTuber 模式）、羁绊/记忆累积（MuseAI 模式——墨衍的羁绊=学习档案）。
- **组合允许**：可指定"底子用 4 号竹青 + 口头禅用 1 号书灵 + 开场白结构用 11 号时间管家"这类混搭。

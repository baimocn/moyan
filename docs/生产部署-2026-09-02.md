> 服务器：阿里云 ECS 8.136.152.54（Ubuntu 24.04, 2 vCPU / 2 GiB）

## 1. 部署拓扑

```
moyan.baimo7715.top (DNS A -> 8.136.152.54)
        │
   nginx :443/:80 (vhost: /etc/nginx/sites-enabled/moyan)
        │  /api/tutor/turn -> proxy_buffering off (SSE 即时推流)
        ▼
uvicorn backend.main:app 127.0.0.1:5001  (systemd: moyan.service, 1 worker)
        │
   SQLAlchemy
        ▼
PostgreSQL 16 (127.0.0.1:5432, db=moyan, user=moyan)
```

- **服务管理**：`systemctl status moyan`（后端）/ `systemctl status nginx`（反代）
- **证书**：certbot 自动续期（`certbot.timer` 每日检查），/etc/letsencrypt/live/moyan.baimo7715.top/
- **代码**：/opt/moyan（venv 3.12 在 /opt/moyan/venv），生产 .env 在 /opt/moyan/.env（600 权限）
- **教材数据**：data/chapters + data/markdown + documents 表 8 本（从本地 SQLite 迁移到 PG）

5. **敏感凭据**：本机 `out/_env_prod.txt` / `out/_pg_pass.txt` 含生产密钥副本（AI key/JWT/PG 密码），请移入密码管理器或删除；服务器侧建议后续换密钥登录（当前 root 密码登录）。
6. **AI key 为复用本地 key**：生产与本地 dev 共用同一把 main/cheap key；若需独立请更换 `/opt/moyan/.env` 后重启。

## 5. 踩坑记录（供后续部署参考）

- **服务器非空**：80/443 已被现有 nginx（bio-quiz 站，baimo7715.top）占用。原 Caddy 方案改挂 nginx vhost + certbot。**部署前先探测端口占用与 server_name 归属**。
- **requirements.txt 缺 slowapi/PyJWT**（部署前置 953946f 漏更新）：生产 `pip install -r` 后 import 直接炸。已补（commit 41fdb35）。
- **paramiko get_pty=True 会卡死**（pty 写端关闭≠EOF）：用标准管道模式（get_pty=False + 逐行读）。
- **Caddyfile 非标准子指令**：`buffer_requests`（v2.9+）与 `max_request_body_size`（不存在）→ 已改 `request_body` 块（commit fd6780d）。
- **下载源**：本机/服务器 GitHub 直连与 cloudsmith 不稳；**ghfast.top 代理可用（405KB/s）**；deb.debian.org 178B/s 太慢不可用。
- **SQLite→PG 迁移**：先 `init_db()` 建表再插（uvicorn lifespan 才会自动建表）。
- **python3 是 3.11**（Ubuntu 24.04 服务器有 python3.12）：建 venv 用 `python3.12 -m venv`。

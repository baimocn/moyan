# 墨衍 · API 契约与双前端接入（2026-08-29）

> 目标：同一套后端 API 同时服务**网站**（浏览器/uni-app H5）与**微信小程序**。
> 本文档是前端接入的唯一契约；后端改动必须同步更新此文档。

## 一、服务与地址

- 后端：FastAPI，默认 `http://127.0.0.1:5001`（`.env`：`MOYAN_HOST`/`MOYAN_PORT` 可改；
  真机/小程序联调设 `MOYAN_HOST=0.0.0.0`）。
- 接口文档（Swagger）：`http://127.0.0.1:5001/docs`。
- CORS：`MOYAN_CORS_ORIGINS`（逗号分隔白名单，默认空=仅同源）。小程序 `wx.request`
  不走浏览器 CORS，不受此项影响。

## 三、教学流事件协议（SSE / enableChunked 共用）

每次 `POST /api/tutor/turn` 返回流，按 `data: {JSON}\n\n` 分帧，流尾 `data: [DONE]`。
**前端逐事件渲染；题目与选项必须原样使用事件内容（前端铁律）。**

| type | 字段 | 前端行为 |
|---|---|---|
| start | session_id/state | 标记轮开始 |
| text-delta | delta | 打字机追加到当前气泡 |
| judge | correctness/score/decision/weak_points/review?/perf? | 判定徽章（对/部分/错+分+下一步） |
| meta | state/kp/persona_name/perf/branch/guard | 路线图高亮、头像、性能角标 |
| question | question{stem,options[{key,text}]} | **渲染题干+选项按钮（点选即作答）** |
| question-batch | questions[] | 章末考题组（逐题作答） |
| report | report{summary,avg_score,weak_points} | 掌握度报告卡 |
| error | error | 错误提示 |
| finish | finish_reason | 收束本轮（question/exam/exam-done/end） |

## 四、网站端接入（已验证：backend/static/tutor.html）

```js
const resp = await fetch("/api/tutor/turn", {method:"POST",
  headers:{"Content-Type":"application/json"},
  body: JSON.stringify({session_id: SID, user_text})});
const reader = resp.body.getReader(), dec = new TextDecoder();
let buf = "";
while (true) {
  const {done, value} = await reader.read(); if (done) break;
  buf += dec.decode(value, {stream:true});
  let i;
  while ((i = buf.indexOf("\n\n")) >= 0) {          // SSE 分帧
    for (const line of buf.slice(0, i).split("\n")) {
      if (!line.startsWith("data: ")) continue;
      const p = line.slice(6).trim();
      if (p === "[DONE]") continue;
      handleEvent(JSON.parse(p));
    }
    buf = buf.slice(i + 2);
  }
}
```
跨源部署时给后端配 `MOYAN_CORS_ORIGINS`（含前端 origin）。

## 五、微信小程序接入（同协议，零后端改动）

小程序无 EventSource；用 `wx.request` 的 chunked 模式读同一个流（基础库 ≥2.20）：

```js
// 小程序里读 SSE（与网站同协议）
wx.request({
  url: BASE + "/api/tutor/turn",
  method: "POST",
  enableChunked: true,                      // 关键：分块接收
  header: {"Content-Type": "application/json"},
  data: {session_id: SID, user_text},
  responseType: "text",
  fail: console.error,
});
const req = /* 上面的 task 引用 */;
let buf = "";
req.onChunkReceived(res => {
  buf += new TextDecoder("utf-8").decode(res.data);   // ArrayBuffer → 文本
  let i;
  while ((i = buf.indexOf("\n\n")) >= 0) {            // 与网站完全相同的分帧解析
    for (const line of buf.slice(0, i).split("\n")) {
      if (!line.startsWith("data: ")) continue;
      const p = line.slice(6).trim();
      if (p === "[DONE]") continue;
      handleEvent(JSON.parse(p));                     // 同一套渲染函数
    }
    buf = buf.slice(i + 2);
  }
});
```

注意：`onChunkReceived` 的 `res.data` 是 ArrayBuffer；中文按 UTF-8 解码，且一个
JSON 事件可能被拆在两个 chunk——**必须缓冲到 `\n\n` 再解析**（上面代码已处理）。

## 六、上线约束（部署阶段补齐）

1. **HTTPS + 备案域名**：微信正式版强制（本地开发用"不校验合法域名"绕过）。
2. **鉴权与限流**：微信 `wx.login` code2session → users 表 → 每用户 token；
   "免费限量"按用户计（规划文档既定）。当前 API 无鉴权，只可在可信环境联调。
3. **CORS 收紧**：正式域名进 `MOYAN_CORS_ORIGINS`，移除 localhost。
4. **传输降级预案**：若 chunked 在低端机不稳，事件协议同样适配 WebSocket
   （后端加 ws 端点即可，协议不变——设计文档第五节预留）。

## 七、M4 增补（2026-09-05，以本节为准）

> 本节补录 2026-08-29 之后的全部契约变化。冲突时**本节覆盖前文**。

### 7.1 端点增补/修订

| 端点 | 方法 | 说明 | 变化 |
|---|---|---|---|
| `/api/documents/{doc_id}` | PATCH | 改名（REN-01，2026-09-04 补录） | 非 admin 过 AI 相符审核，不符 **422**（detail=拒绝理由）；同名短路 `unchanged:true`；限流 10/min |
| `/api/documents` / `/{doc_id}` | GET | 书架/详情 | **CMP-02 可见性**：返回 `shared=true` 或本人上传的文档（admin 全见）；不可见一律 404；文档对象新增 `shared` 字段 |
| `/api/admin/documents/{doc_id}/share` | POST | **新增**（CMP-02） | 一键下架/恢复，body `{shared:bool}`，仅 admin（403）；下架后公共书架与详情对他人 404 |
| `/api/admin/smoke` | GET | **新增**（OBS-01） | 冒烟探针记录（最近 50 条，新在前），仅 admin |
| `/api/privacy` | GET | **新增**（CMP-01） | 隐私与数据保留策略（免鉴权），网页端 /privacy 页与小程序告知页共用 |

### 7.2 行为变化（前端必须处理的状态码）

| 状态码 | 端点 | 语义 | 前端动作 |
|---|---|---|---|
| **404** | `/api/tutor/turn`、`/api/study/resume`、`/api/study/review-session/*` | SEC-01 会话归属：非 owner 一律 404（不暴露存在性）；老会话重启后首次访问也会正常续学 | 提示"会话已失效，请重新开始" |
| **409** | `/api/tutor/turn` | SEC-03 同会话并发：上一轮仍在进行 | 静默禁用发送按钮/提示"上一轮还在进行中"，**不要当错误弹窗** |
| **429** | `/api/tutor/start`、`/api/tutor/turn` | SEC-04 日预算硬顶（MOYAN_DAILY_TOKEN_HARD）；另有既有 30/min 限流 429 | 按 Retry-After 提示稍后再试 |
| **503** | `/api/upload` | CMP-02 审核服务不可用（fail-closed） | 提示"审核服务暂不可用，请稍后重试"并可重试 |

### 7.3 文档对象新字段

- `documents[]` 与详情新增 **`shared: bool`**（是否在公共书架；管理台可下架）

### 7.4 不变项

- SSE 教学协议（事件类型/`[DONE]`）不变；上传 429/5/h、content_hash 去重、免登录三态身份均不变

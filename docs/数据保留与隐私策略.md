# 墨衍 · 数据保留与隐私策略

*版本 2026-09-05（CMP-01）· 与 `GET /api/privacy` 同源，网页端展示于 /privacy*

## 收集范围

| 数据 | 内容 | 目的 |
|---|---|---|
| 教材文件 | 上传的 PDF/MD 与解析结果（章节、切片） | 教学服务 |
| 对话数据 | 与 AI 同桌的全部交互（讲解/提问/判定/复习） | 教学服务 + 构建教学对话语料（产品目标） |
| 学习档案 | 薄弱点、掌握度、FSRS 复习排程 | 教学服务 |
| 用量观测 | AI token 台账、页面浏览（设备标识） | 成本核算与统计 |

## 保留期限（滚动清理）

- 教学与对话数据：**24 个月**
- 用量与浏览台账：**24 个月**
- 到期自动滚动删除；用户可经管理员通道请求提前删除/导出

## 身份与保密性说明

- 网页免登录身份 = 浏览器本地设备标识（X-Device-Id），**无保密性**；
  请勿在对话中提交敏感个人信息
- 微信登录用户以 openid 标识

## 联系通道

删除/导出请求：联系站点管理员（管理台可见请求范围）。

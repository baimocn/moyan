# Plan 02-01 — 文档删除与联级清理

对应需求：DOC-01、DOC-02、DOC-03、VEC-05（清理链挂点：删 chunks 预留注释）
对应路线图 Phase 2 成功标准 1/2/4（标准 3 生产实测在部署步执行）。

## Tasks

### T1 DELETE 端点（backend/routers/documents.py）
- `@router.delete("/documents/{doc_id}")`，依赖 `require_admin`
- 单事务按 FK 序删：turns/judgements（session_id 子查询）→ weaknesses → strategy_logs → teaching_sessions → tasks → documents
- 事务后删文件：markdown、chapters 目录（shutil.rmtree）、uploads 目录；缺失容错
- 返回 `{ok: true, deleted: {sessions, turns, judgements, weaknesses, strategy_logs, tasks}}`
- 验收：全链无残留；404；403

### T2 测试（backend/tests/test_doc_delete.py）
- fixture：造 doc + task + session + turn + judgement + weakness + strategy_log + 文件产物
- admin 删除 → 200 + DB 0 残留 + 文件 0 残留
- 非 admin（Bearer 普通）/ 设备匿名 → 403
- 删后重复删 → 404；不存在 doc → 404
- 级联计数正确

### T3 前端入口（frontend-web，仅 web）
- `src/api/auth.js` 已有 me()? 确认后：登录态下拉 /me 取 role 存 pinia
- HomeView 书架卡 admin 显示「删除」→ 确认弹层（写明连学习记录）→ DELETE → 刷新列表
- 普通用户/匿名不可见删除按钮
- 验收：构建通过；小程序端零改动

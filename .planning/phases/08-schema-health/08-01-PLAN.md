# Plan 08-01 — Schema 健康化 + alembic 基线

对应需求：SCHEMA-01..06（ROADMAP M4 Phase 8）；调研 RESEARCH.md R4。
执行窗口论据：生产最大表 32 行，所有 ALTER 均为秒级。

## Tasks

### T1 SCHEMA-01 索引与唯一约束补齐
- 生产 DDL（经 alembic 0002）：`CREATE INDEX IF NOT EXISTS ix_documents_content_hash`；
  `CREATE UNIQUE INDEX user_profiles_email_key ON user_profiles(email)`
- 模型已声明（index=True / unique=True），create_all 新库自带——仅补存量库

### T2 SCHEMA-02 台账主键 bigint
- 模型：`backend/models/usage.py`、`vec.py` id 改 `BigInteger`
- 生产 DDL：`ALTER SEQUENCE x_id_seq AS bigint` + `ALTER TABLE x ALTER COLUMN id TYPE bigint`（×3）

### T3 SCHEMA-03 jsonb 统一
- `backend/models/db.py` 新增公共 `JSONType = JSON().with_variant(JSONB(), "postgresql")`
- documents(4)/turns(1)/judgements(1)/teaching_sessions(5) 的 JSON 列全部换用 JSONType
- 生产 DDL：逐列 `ALTER ... TYPE jsonb USING col::jsonb`（jsonb 输入可重入）

### T4 SCHEMA-04 CHECK 约束（域已核实：TutorState 7 值；mastery low/mid/high）
- documents.status IN (done,processing,failed)／teaching_sessions.state IN (TutorState 7 值)／
  turns.role IN (user,assistant)／weaknesses.mastery IN (low,mid,high)／
  weaknesses.fsrs_state BETWEEN 1 AND 3／user_profiles.auth_type IN (wx,web)
- 模型：`__table_args__` CheckConstraint；生产：DO $$ 块幂等添加（先 SELECT DISTINCT 核实存量值）

### T5 SCHEMA-05 weaknesses 业务唯一键 + upsert 修复
- 唯一索引 (user_id, doc_id, skill_id) WHERE user_id IS NOT NULL（PG 部分索引）
- **修 upsert_weakness**：user_id None 时必须 `user_id.is_(None)` 过滤——现状无过滤会跨用户抓行更新
- 验收：A 行存在时 None/B 路径各建新行，不动 A 行

### T6 SCHEMA-06 alembic 基线
- `alembic.ini` + `migrations/env.py`（读 db_settings.db_url，target_metadata=Base.metadata）
- 版本 0001 baseline：`Base.metadata.create_all(op.get_bind())`（棕地惯例，from-zero 即等价 schema）
- 版本 0002 schema_health：T1-T5 全部 DDL（幂等：IF NOT EXISTS / DO 块 / 可重入 ALTER）
- 生产路径：`pip install alembic`（venv）→ `alembic stamp 0001` → `alembic upgrade head`
- requirements.txt 加 alembic>=1.13

### T7 测试与回归
- 新 `test_schema_health.py`：metadata 断言（bigint/JSONB/CHECK/unique）+
  upsert 隔离 + SQLite 侧行为不变
- 全量 pytest；`git diff` 无前端；部署后 pg_indexes 复核输出存档

## Risks

- CHECK 与存量数据冲突：先跑 SELECT DISTINCT 核实，冲突则先清洗再挂约束
- alembic 在生产 venv 首次安装：仅加包，不动运行代码；失败可 pip uninstall 回滚
- json→jsonb 后 SQLAlchemy JSON 读取兼容（PG 驱动透明）；测试覆盖读写往返

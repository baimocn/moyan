## Tasks

### T1 SEC-01 会话归属校验（5 端点）
- 文件：`backend/engine/tutor/service.py`（新增 `require_owned_session(session_id, requester_openid)`）、
  `backend/routers/tutor.py`（turn）、`backend/routers/study.py`（resume / review-session/{id} / answer）
- 设计：
  - 归属判定：`session.user_id == requester.openid`；`user_id IS NULL`（老数据/游客）仅允许
    `web_anon` 与 admin 访问，其余 404
  - 一律返回 **404**（不返 403——不向探测者暴露会话存在性）
  - start 无需校验（会话在此时创建，owner=请求者）
- 验收：新测试 `test_session_ownership.py`：
  用户 A 建会话 → B（另一 openid）turn/resume/review 三个端点全 404；
  A 正常 200；NULL-owner 会话 web_anon 可续、实名用户 404；admin 可访 NULL-owner

### T2 SEC-02 生成上限参数化
- 文件：`backend/settings.py`（`gen_max_tokens: int = 4000`，MOYAN_GEN_MAX_TOKENS）、
  `backend/engine/providers.py`（chat / chat_stream / cheap 未显式传 max_tokens 时注入默认；
  cheap 档取 `min(默认, 1500)`）
- 设计：调用方已显式传 max_tokens 时不覆盖（保持向后兼容）；
  数值来自 env，不在代码里散落魔法数
- 验收：单测断言 mock 路由收到的 kwargs 含 max_tokens 且值来自 settings；
  monkeypatch 改 env 值生效；现有引擎测试全绿（显式传参路径不受影响）

### T3 SEC-03 同会话并发锁
- 文件：`backend/engine/tutor/service.py`（`handle_turn` 入口）
- 设计：
  - 进程内 `defaultdict(asyncio.Lock)` 按 session_id 加锁，`lock.acquire()` 非阻塞
  - 拿不到 → `HTTPException(409, "上一轮仍在进行中")`（在 StreamingResponse 返回**之前**抛）
  - `try/finally` 确保异常路径释放；单 worker 架构下进程内锁足够，
    多 worker 演进时在代码注释标注"扩 worker 需换 PG advisory lock"
- 验收：并发两 turn 同 session → 一个 200 一个 409；构造 handle_turn 抛异常 →
  锁已释放（第三次可正常进入）；不同 session 互不阻塞

### T4 SEC-04 日预算熔断
- 文件：`backend/settings.py`（`daily_token_budget: int = 0` 0=关闭、`daily_token_hard: int = 0`）、
  `backend/ledger.py`（新增 `tokens_today() -> int`：`SELECT COALESCE(SUM(total_tokens),0)
  FROM ai_usage WHERE created_at >= date_trunc('day', now())`，进程内缓存 60s）、
  `backend/engine/providers.py` 或 Router 调用点（消费闸门）
- 设计：
  - `tokens_today() > daily_token_budget > 0` → 主/备引擎强制降级 cheap（预算软顶）
  - `> daily_token_hard > 0` → 直接抛 `BudgetExceeded`，turn 端点映射 429（硬顶）
  - 两者默认 0 = 关闭，现网行为零变化；开启由 env 决定
  - 记账本身不熔断（台账必须永远能写）
- 验收：monkeypatch budget=1/hard=0 → 调用走 cheap（ai_usage 行 engine='cheap'）；
  budget=1/hard=2 → 429；默认 0 → 行为与现状逐字节一致（现有测试不改动即绿）

### T5 回归与交付
- 全量 `python -m pytest backend/tests/ -q --basetemp=out/_pytest_tmp`

## Risks

- 归属校验可能误伤"老数据 NULL owner + 实名用户"的历史会话续学场景——
  测试显式覆盖该组合；生产灰度后观察 404 率（ai_usage 不可用时看 uvicorn 日志）
- max_tokens 注入若与某模型供应商参数冲突（如不支持该字段）——
  providers 层 try/except 降级为不传并 logging.warning，不阻塞主流程
- 预算 SUM 查询频率：60s 进程内缓存摊薄；单 worker 无缓存一致性问题

- T4 依赖 ai_usage 表已在生产运行（Phase 3 交付，实测 6 行）
